# PRD 渐进探索

仅在问题互相依赖、无法在当前上下文完整表述时执行本流程。

1. 调用 `grilling` 确认本任务的目标和非目标，再广度优先识别当前能够准确表述的问题。完成：目标和非目标已确认，未为依赖不足的区域编造问题。
2. 在 `prd.md` 的“未决问题”中维护“当前前沿”“后续问题”和“尚未明确”三个三级标题。当前前沿只放无未解决依赖的问题；后续问题写出阻塞它的 Q ID；尚未明确只记录依赖前序答案才能准确提问的区域。完成：每个开放区域只属于一个层级，依赖关系可追踪。
3. 为准确表述的问题分配从 `Q-001` 开始的稳定 Q ID，并写明问题、期望答案和阻塞关系；尚未明确的区域不分配 ID。完成：所有可表述问题均有唯一稳定 ID。
4. 每轮处理当前前沿中全部互不依赖的问题。事实问题自行读取必要证据；必须由用户判断的问题合并到一次 `grilling`，只有高风险、答案冲突或仍有依赖时才单独提问；含糊、一词多义或与 `CONTEXT.md` 冲突的表达调用 `sw-domain-modeling`。完成：当前前沿已由证据或用户决定收敛，没有代答真实取舍，也没有逐题制造无必要的往返。
5. 每解决一个问题，立即把决定、理由和影响连同 Q ID 追加到 `decisions.md`，同步 PRD 正文，删除仍把该 Q 视为未解决前提的旧表述，再重新计算三个层级。完成：PRD、决策记录和未决问题层级反映同一当前事实。
6. 当前前沿为空但仍有后续问题或尚未明确时，记录实际阻塞并停止。完成：全部问题已收敛，或剩余阻塞具有明确依赖且没有被改写为默认假设。

# CONTEXT.md 格式

`CONTEXT.md` 位于工作流仓库根目录，是项目长期记忆入口。需要该上下文的 Skill 在自身契约中显式声明。

```markdown
# {项目名称}

{一到两句话说明项目目标和存在理由。}

## 专业术语

**订单**：
{一到两句话定义它是什么。}
_避免使用_：交易单、购买记录

## 关键决策

- [ADR-0001 服务端决定身份归属](./adr/0001-server-owned-identity.md) — accepted · backend/auth · 客户端不得声明用户或租户归属。
```

## 专业术语规则

- 多个词表达同一概念时，只保留一个规范名称，并把其他名称列入 `_避免使用_`。
- 定义说明“它是什么”，保持一到两句话；行为规则、实现方式和验收要求写到对应任务文档。
- 只收录项目特有且会反复使用的概念；通用技术概念不属于专业术语。
- 一词多义时拆成不同术语，不用宽泛定义掩盖差异。

## 关键决策索引规则

- 每个当前或历史 ADR 都有且只有一个索引项，按编号升序排列。
- 索引项包含链接、状态、影响范围和一句话摘要。
- `accepted` 表示当前有效；被替代时写 `superseded by ADR-NNNN`，约束消失时写 `deprecated`。
- ADR 正文只在当前任务命中其项目、仓库或模块范围时读取。
- 首个 ADR 出现时才创建根目录 `adr/`。
